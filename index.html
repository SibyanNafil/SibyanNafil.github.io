[Skripsi] Pengembangan Algoritma Path Planning Pada Sistem 4-Wheeled Omnidirectional Cellular Conveyor Berbasis Raspberry Pi

Periode: Januari 2026 - Mei 2026

Latar belakang

Skripsi saya membahas mengenai pengembangan algoritma path planning untuk sistem modular 4-wheeled omnidirectional cellular conveyor guna mengoptimalkan proses pemindahan material secara otomatis. Merancang mekanisme dynamic routing pada sistem conveyor berbasis grid, dengan setiap cell dikendalikan oleh mikrokontroler individual dan dikoordinasikan melalui Raspberry Pi sebagai pengendali pusat. Sistem yang dikembangkan meningkatkan fleksibilitas dan efisiensi routing dibandingkan dengan sistem conveyor konvensional yang menggunakan jalur tetap.

Peran
  • Merancang arsitektur sistem kendali dengan Raspberry Pi 5 sebagai master dan beberapa mikrokontroler ESP32 sebagai slave node, yang masing-masing mengendalikan satu cell konveyor.
  • Melakukan kalibrasi RPM motor penggerak pada seluruh cell konveyor dengan tingkat akurasi hingga 97%
  • Merancang dan mengimplementasikan algoritma Dijkstra untuk path planning pada weighted grid graph 8 arah
  • Mengembangkan antarmuka GUI monitoring secara real-time untuk visualisasi dan pengendalian sistem.
  • Mengimplementasikan pelacakan visual berbasis ArUco marker menggunakan OpenCV untuk melacak pergerakan box.

Soil Nutrients Monitoring

Periode: Febuari 2024 - Oktober 2024

Latar belakang

Soil Nutrients Monitoring merupakan perangkat monitoring tanah portabel berbasis IoT yang dikembangkan untuk mengukur kandungan NPK, pH, suhu, dan kelembapan tanah sebagai alternatif pengujian laboratorium yang lebih cepat dan tidak merusak sampel tanah. Analisis kondisi tanah dilakukan dengan mengacu pada standar Kementerian Pertanian Republik Indonesia untuk menghasilkan penilaian kondisi tanah dan rekomendasi tanaman yang sesuai. Protokol komunikasi Bluetooth Low Energy (BLE) digunakan untuk mengirimkan data hasil pengukuran yang tersimpan pada mikrokontroler ke aplikasi mobile untuk proses analisis dan penyajian informasi. Perangkat ini mencapai Tingkat Kesiapterapan Teknologi (TKT) 4 melalui proses validasi di laboratorium, dengan akurasi sensor di atas 95%. Proyek ini juga berhasil lolos finalis Pekan Ilmiah Mahasiswa Nasional (PIMNAS) ke-37.

Peran
  • Memimpin pengembangan perangkat keras secara end-to-end, meliputi perancangan arsitektur sistem berdasarkan kebutuhan dan permasalahan, desain perangkat keras 3D, perancangan skematik PCB, pemrograman mikrokontroler, fabrikasi dan perakitan perangkat keras, hingga kalibrasi sensor.
  • Melakukan kalibrasi berbagai sensor, meliputi sensor NPK, pH, suhu, dan kelembapan tanah, dengan tingkat akurasi di atas 95%.
  • Melakukan pengujian fungsional dan validasi untuk memastikan sistem perangkat keras beroperasi secara andal serta memenuhi kebutuhan dan kinerja yang telah ditentukan.
Tools & teknologi

  • Sensor Suhu
  • Sensor pH
  • Sensor NPK
  • Sensor Kelembapan Tanah
  • Internet of Things (IoT)

Automatic Nutrition Mixing for Hydroponics

Periode: Juli 2023 – Oktober 2023

Latar belakang

Proyek ini bertujuan untuk mengembangkan sistem pencampuran nutrisi otomatis berbasis IoT untuk budidaya hidroponik NFT guna mengotomatisasi proses pencampuran nutrisi AB Mix, menggantikan proses pemantauan nutrisi secara manual yang berisiko menyebabkan ketidakkonsistenan dosis dan kesalahan manusia. Mengintegrasikan mikrokontroler Arduino Mega dengan modul Wi-Fi ESP8266, sensor TDS, sensor ketinggian air, dan sensor aliran air, serta platform IoT Blynk untuk memungkinkan pemantauan dan pengendalian konsentrasi nutrisi, ketinggian air, dan laju aliran secara real-time melalui aplikasi mobile. Alat ini berhasil memenangkan juara 2 efektif pada kompetisi AITeC5 (Agricultural Innovation Technology Competition ke-5).

Peran
  • Memilih, memasang, mengkalibrasi, dan menguji sensor TDS, sensor ketinggian air, serta sensor aliran air.
  • Merancang rangkaian kelistrikan, menentukan wiring, power supply, driver aktuator, serta integrasi antar-komponen.
  • Melakukan pengujian sistem, kalibrasi sensor, validasi dosis nutrisi, dan mengevaluasi performa alat.
Tools & teknologi
  • Arduino Mega + ESP8266
  • Sensor TDS Meter
  • Sensor Water Level
  • Sensor Water Level
  • Peristaltic Pumps
  • Blynk IoT

Robot Monitoring Greenhouse Berbasis IoT

Periode: Juli 2023 – Oktober 2023

Latar belakang

Mengembangkan robot monitoring greenhouse berbasis IoT yang berfungsi untuk memantau kondisi lingkungan secara real-time, meliputi suhu, kelembapan, dan parameter lingkungan lainnya. Sistem dirancang untuk membantu petani memperoleh informasi kondisi greenhouse secara lebih cepat dan mudah melalui pemantauan jarak jauh, sehingga kondisi lingkungan dapat dipantau secara berkala dan tindakan yang diperlukan dapat dilakukan secara lebih responsif untuk mendukung pertumbuhan tanaman yang optimal.

Peran
  • Merancang skema sistem kelistrikan untuk robot monitoring greenhouse.
  • Mendesain rangka dan body robot dalam bentuk 3D menggunakan perangkat lunak Autodesk Inventor.
  • Melakukan proses wiring dan integrasi sistem kelistrikan pada robot monitoring greenhouse.
  • Melakukan pengujian sistem, troubleshooting, dan debugging untuk memastikan seluruh sistem berfungsi secara optimal.
